# Xiaomi MiTV-MOOQ2 (codename croods, the MOOQ0 board on newer firmware), Android TV 11,
# firmware RTM4.220307.164.8238. MediaTek, ro.adb.secure=1, 1920x1080 at 320 dpi.
# Stock launcher: com.google.android.tvlauncher (classic Android TV home: Inicio / Tienda / Aplicaciones).
# Live TV app: com.mediatek.wwtv.tvcenter, which also owns the input picker (com.mitv.livetv.input.SelectInputActivity).
#
# Apply:   TV_HOST=<tv ip> tools/disable.sh examples/xiaomi-mitv-mooq2/debloat.txt
# Undo:    TV_HOST=<tv ip> tools/restore.sh examples/xiaomi-mitv-mooq2/debloat.txt
# Everything is DISABLED for user 0, not uninstalled. Comment out any line you want to keep.
#
# Tested on this firmware: disabled in five batches with a screenshot after each. The Google Play sponsored
# row is gone, the Source button still opens "Fuente de entrada" (HDMI 1-3, AV, TV) with PatchWall off, and
# launcher/ owns Home. A first-day report, not the few days of living with it that CONTRIBUTING.md asks for.
#
# HOME on this build: only tvlauncher and com.android.tv.settings/.system.FallbackHome claim it.
# setupwraith does not claim HOME here and the saved Wi-Fi belongs to android.uid.system, so it stays enabled.
# com.duokan.factorytest (the MOOQ0 quirk) is not installed on this firmware.
#
# DO NOT DISABLE on this model, checked with dumpsys package:
#   com.mediatek.wwtv.tvcenter    Live TV, HDMI playback and the input picker
#   com.mediatek.tvinput          HDMI 1-3, AV and the tuner
#   mitv.service                  TvServer, TvSettingService
#   com.mitv.overseaservice       netflixService (the remote's Netflix button)
#   com.mi.bluetooth, com.xiaomi.android.tvsetup.partnercustomizer (BleRcActivity)   remote pairing
#   com.xiaomi.tvqs.overseas      TvQSReceiver, quick settings
# Kept by request: Chromecast (mediashell), Google Assistant (katniss), firmware updates
